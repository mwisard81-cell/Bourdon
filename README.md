# Bourdon

Musique pour tes vidéos et boîte à rythmes, directement dans le navigateur.

**Ouvrir l'appli : https://mwisard81-cell.github.io/Bourdon/**

L'appli est protégée par un mot de passe. Ce dépôt ne contient qu'une version chiffrée : sans le mot de passe, son contenu est illisible.

Le dossier `samples/` contient des sons d'instruments du Fluid Soundfont « FluidR3_GM » de Frank Wen, sous licence Creative Commons Attribution 3.0 (voir `samples/CREDITS.txt`).
